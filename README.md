# TEST Tenant Service LIFF

Static LIFF proof of concept for TEST tenant services.

## Demo

https://piyanutapp.github.io/poctestlineliffhuman/

The app currently uses mock invoice, document, payment, and service-request data.

## Page structure

- Dashboard: `https://piyanutapp.github.io/poctestlineliffhuman/`
- วิธีการใช้งาน: `https://piyanutapp.github.io/poctestlineliffhuman/howto/`
- ติดต่อเรา: `https://piyanutapp.github.io/poctestlineliffhuman/contact/`

Legacy links such as `?panel=howto` and `?panel=contact` are redirected to the new pages.

## Recommended LIFF Rich Menu paths

Use the same LIFF app with distinct paths:
